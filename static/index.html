合成流程

1. 视频帧提取 — ffmpeg 将视频拆成 PNG 帧序列
2. 音频特征提取 — Whisper 模型提取多层音素特征
3. 人脸关键点检测 — mmpose + DWPose 检测面部关键点，计算 BBox
4. VAE 编码 — Stable Diffusion VAE 将人脸区域编码为 latent
5. UNet 推理 — 条件 UNet + PositionalEncoding，音频驱动口型
6. VAE 解码 — latent 解码回 256×256 人脸图像
7. FaceParsing 混合 — 人脸分割 mask + 高斯模糊，混合回原视频
8. ffmpeg 合成 — 帧序列 + 音频合成最终 MP4

素材说明

服务器文件 — 扫描容器内素材目录 /app/materials、/app/data、/app/input（挂载方式见 docker-compose.yml），点选即用，无需上传
上传本地 — 直接上传视频/音频文件到服务器再合成，任务结束后临时文件自动清理
建议 — 视频素材长度 ≥ 音频长度，避免画面循环重复（音频更长时任务会提示回环续播）

极速版 vs 精修版

参数极速版精修版影响
batch_size82速度主因：越大 GPU 利用率越高 (8GB卡建议 8)
blur_factor1 (锐利)3 (柔滑)边缘过渡质量
parsing_modejaw (仅下巴)neck (含脖子)混合区域范围
extra_margin515下巴下方额外像素
upper_boundary35%55%上半脸保留比例
另有「极速对话」档：batch_size=16 且跳过质感统一（face parsing），适合对话/批量场景追求最快出片；多个任务同时提交会自动在 GPU 上排队串行执行。

参数速查 (自定义模式)

参数默认说明
versionv15v15 口型更准，v1 更稳定
parsing_modejaw面部混合范围：jaw(下巴)/neck(脖子)/raw(全脸)
blur_factor2模糊核系数 (内部 ×0.01)，越小越锐利
upper_boundary_ratio50%上半脸保留比例
extra_margin10人脸裁剪下巴下方额外像素
batch_size8推理批大小 (RTX4080 建议 8-32)
bbox_shift0人脸框偏移 (v15 固定为 0)

1. 健康检查

GET /api/health
curl http://localhost:5000/api/health

2. 获取参数列表

GET /api/params
curl http://localhost:5000/api/params

3. 提交合成任务

POST /api/synthesize
上传视频+音频文件并提交合成任务。返回 task_id 用于后续查询。
curl -X POST http://localhost:5000/api/synthesize \
  -F "video=@video.mp4" \
  -F "audio=@audio.wav" \
  -F "mode=fast"
模式参数 mode 支持四个值：fast（极速版）、quality（精修版）、turbo（极速对话，跳过质感统一最快出片）、custom（自定义）。多个任务同时提交会自动排队串行执行：
curl -X POST http://localhost:5000/api/synthesize \
  -F "video=@video.mp4" \
  -F "audio=@audio.wav" \
  -F "mode=custom" \
  -F "version=v15" \
  -F "parsing_mode=jaw" \
  -F "blur_factor=2" \
  -F "upper_boundary_ratio=50" \
  -F "extra_margin=10" \
  -F "batch_size=8" \
  -F "bbox_shift=0"
或指定服务器已有文件路径（/app/materials 或 /app/data 内）：
curl -X POST http://localhost:5000/api/synthesize \
  -F "video_path=/app/materials/video.mp4" \
  -F "audio_path=/app/materials/audio.wav" \
  -F "mode=fast"

4. 查询任务状态

GET /api/status/<task_id>
curl http://localhost:5000/api/status/abc12345
返回: { task_id, status, progress, message, info, params }

5. 下载结果

GET /api/download/<task_id>
curl -O http://localhost:5000/api/download/abc12345

6. 取消任务

POST /api/cancel/<task_id>
curl -X POST http://localhost:5000/api/cancel/abc12345
取消正在运行或排队中的任务。完成后任务状态变为 cancelled。

7. 列出已有文件

GET /api/files
curl http://localhost:5000/api/files
扫描 /app/materials、/app/data 与 /app/input，返回视频和音频列表（含大小 size_mb 与时长 duration 秒），最近放入的排前面。

8. 清空已结束任务记录

POST /api/tasks/clear
curl -X POST http://localhost:5000/api/tasks/clear -d "delete_files=true"
清除完成/失败/取消的任务记录；delete_files=true 时同时删除对应 output/<task_id>/ 输出目录，默认仅清记录。

9. 预处理缓存管理

GET /api/cache
POST /api/cache/clear
curl http://localhost:5000/api/cache
curl -X POST http://localhost:5000/api/cache/clear
查看/清空人脸检测+VAE编码缓存（cache/preprocess）。缓存可随时重建，清空只影响同素材下次首次合成的速度。

启动服务

进入项目目录后执行以下命令：
# Windows：进入项目目录后双击 start.bat（首次运行会自动导入 image.tar）
# 或手动执行:
docker compose up -d

# 查看日志，等待模型加载完成:
docker logs -f musetalk
# 看到 "[READY] API server starting on port 5000" 表示就绪

# 浏览器打开 http://localhost:5000

重启服务

docker compose restart

关闭服务

# 停止容器（保留容器，下次 start 更快）:
docker compose stop

# 或完全删除容器:
docker compose down

查看状态

docker ps --filter "name=musetalk"

# 查看日志:
docker logs --tail 50 musetalk
