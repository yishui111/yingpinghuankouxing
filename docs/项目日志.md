# 项目日志

> 记录项目状态与每次改动；最新条目在最上面。

## 2026-09-05 代码与功能优化

- **GPU 排队**：推理改为信号量串行（`_gpu_slot`），多任务并发提交不再抢占显存；排队/运行状态在任务消息中可见；`/api/reload` 在有任务进行时拒绝执行（409）。
- **ffmpeg 安全与提速**：全部 `os.system` 字符串拼接改为 `subprocess` 列表参数（路径含空格/中文不再出错，杜绝命令注入）；音视频封装第二步改 `-c:v copy`（省一次全片重编码）并加 `+faststart`（网页预览秒开）；帧提取失败立刻报明确错误。
- **修 bug**：目录输入时 `save_dir_full` 未定义的 UnboundLocalError；混合阶段单帧 resize 失败改回退原帧（保持帧号连续，此前会静默截断视频）；未检测到人脸时给出明确错误；blending 里 `_color_match`/`_reinject_noise` 重复定义去重（保留 mask 限内生效版，消除混合边界"方框"色差），高斯模糊核钳制到图像尺寸内。
- **安全加固**：上传扩展名白名单；`video_path/audio_path` realpath 限制在容器 /app 内；Flask `MAX_CONTENT_LENGTH=4GB` + /api 统一 JSON 404/413/500。
- **新功能**：任务记录清理 `POST /api/tasks/clear`、预处理缓存查看/清理 `GET /api/cache`、`POST /api/cache/clear`（控制台「任务列表」卡片新增两个维护按钮）；`/api/files` 增扫 /app/input 并带大小/时长；任务 info 探测音视频时长，音频长于视频提前提示回环续播；上传临时文件任务结束自动删除；任务记录上限 100 条自动修剪。
- **前端**：新增「极速对话」档（对应后端 turbo 预设）；XHR 上传进度条；刷新页面自动恢复进行中任务的轮询；文件列表转义防注入并显示大小/时长；完成时显示回环提示。
- 同步更新 README.md、AGENTS.md、控制台内 API 文档。
