# 启动速查（yingpinghuankouxing）

在**项目根目录**执行（脚本用 `%~dp0` 定位自身，可放在任意盘符路径下）：

| 操作 | 命令 |
|------|------|
| 启动 | `启动.bat`（或 `start.bat`，Linux/macOS 用 `./start.sh`） |
| 停止 | `关闭.bat`（或 `stop.bat`，Linux/macOS 用 `./stop.sh`） |
| 查看状态 | `状态.bat`（或 `status.bat` / `status.sh`） |
| 查看日志 | `docker logs -f musetalk` |

> 首次启动前需先把 `image.tar`（约 16.9GB 完整镜像）放到项目根目录，
> `start.bat` 检测到镜像未导入时会自动 `docker load`（约 5-10 分钟）。
> 镜像获取方式见 `README.md`「大件资源下载」与 `DEPLOY.md`。

如果容器状态异常，先清理再启动:

```
docker rm -f musetalk
```
